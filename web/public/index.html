MAKE YOURSELF HEARD
Station settings
Exactly six letters or digits.
Device names appear after microphone permission. Unsupported output selection uses your system speaker.
Reception detects both profiles automatically. Keep this app visible while using radio audio. Headphones or a radio interface prevent acoustic feedback.


LESS TYPING. MORE TALKING.
Message macros
Use the buttons below, or Ctrl+X then 1–9. Macros insert text; they never transmit automatically. Leave a slot empty to disable it.


EVERYTHING AT HAND
All actions
Keyboard: Ctrl+X, release, then the action key. Esc cancels. Up/Down recalls sent messages.


Install BlackSquelch
Use your browser’s Install app or Add to Home Screen command. Installation is supported by current Chromium browsers and Safari on iPhone and iPad; other browsers may not offer it.
The app stays on your device and opens offline after its first complete load. Microphone permission is still required for radio audio.
